Ajuda do Dashboard

Como usar:

  1. Carregue um arquivo Excel com os dados financeiros
  2. Selecione o mês base para análise
  3. Opcionalmente, selecione um mês para comparação
  4. Clique em "Comparar" para gerar os gráficos e tabelas

Legenda:

  • Valores positivos são mostrados em verde
  • Valores negativos são mostrados em vermelho
  • Indica aumento em relação ao período anterior
  • Indica redução em relação ao período anterior

Dicas:

  • Passe o mouse sobre os gráficos para ver detalhes
  • Use os botões de exportação para salvar os resultados
  • Clique em "Mostrar/Ocultar Métricas" para simplificar a visualização
